# Breen Base Staking

A simple staking smart contract built on Base Sepolia using Hardhat and OpenZeppelin.

## Features

* ERC-20 token (BreenToken)
* Deposit / stake tokens
* Withdraw tokens
* View personal staked balance
* View total staked amount

## Network

* Base Sepolia (Chain ID: 84532)

## Tech Stack

* Solidity 0.8.20
* Hardhat
* OpenZeppelin Contracts
* Ethers.js
